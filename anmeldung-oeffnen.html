#mitspielen-anmelden

Anmeldung steuern

Hiermit schaltest du das Anmeldeformular für die anderen frei oder sperrst es wieder. Diese Seite bleibt privat — nur das Formular selbst wird geteilt.

Der Status wird lokal in diesem Browser gespeichert (localStorage). Öffne anmeldung.html im selben Browser, damit der Status übernommen wird — bei einer echten Mehrgeräte-Nutzung braucht es zusätzlich einen kleinen Server oder eine geteilte Datenquelle.
